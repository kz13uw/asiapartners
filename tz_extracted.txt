1. НАЗНАЧЕНИЕ И ЦЕЛИ СИСТЕМЫ
Система предназначена для автоматизации закупочной деятельности, взаимодействия с контрагентами (поставщиками), проведения тендеров на понижение, а также обеспечения юридической значимости действий участников за счет интеграции с электронной цифровой подписью (ЭЦП).
2. СТЕК ТЕХНОЛОГИЙ И АРХИТЕКТУРА
2.1. Технологический стек
Backend: Python 3.11+, FastAPI, GoLang
Frontend: React.js
База данных: PostgreSQL
Кэширование и очереди: Redis
Контейнеризация: Docker
2.2. Архитектурные принципы
Архитектурный стиль: Микросервисная архитектура. Каждый модуль или группа связанных функций разворачивается в отдельном Docker-контейнере.
Взаимодействие: Асинхронное взаимодействие между сервисами через брокер сообщений и синхронное через REST API.
API Gateway: Единая точка входа для фронтенда, обеспечивающая маршрутизацию запросов к микросервисам, логирование и первичную проверку JWT-токенов.
